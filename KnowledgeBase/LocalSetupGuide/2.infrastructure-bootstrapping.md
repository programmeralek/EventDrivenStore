# Local Setup — Infrastructure Bootstrapping

This document describes **how to start the shared infrastructure** required by all services.

Use this after confirming the prerequisites in `1.prerequisites.md`.

---

## What Gets Started

The following infrastructure containers are started locally:
- Eureka (service discovery)
- Kafka + Zookeeper (event transport)
- MySQL (Orders database)
- MSSQL (Inventory database)
- MariaDB (Billing database)

---

## Start All Infrastructure

Run these from the repository root:

```bash
cd /path/to/EventDrivenStore

docker compose -f infrastructure/eureka-compose.yml up -d
docker compose -f infrastructure/kafka-compose.yml up -d
docker compose -f infrastructure/mysql-orders-compose.yml up -d
docker compose -f infrastructure/mssql-inventory-compose.yml up -d
docker compose -f infrastructure/mariadb-billing-compose.yml up -d
```

---

## Verify Containers

```bash
docker ps --format "table {{.Names}}\t{{.Ports}}"
```

Expected ports (local):
- Eureka: `8761`
- Kafka: `9092`
- Zookeeper: `2181`
- Orders MySQL: `3310`
- Inventory MSSQL: `1433`
- Billing MariaDB: `3307`

---

## Reset / Teardown (Optional)

If you need to reset local state:

```bash
docker compose -f infrastructure/eureka-compose.yml down
docker compose -f infrastructure/kafka-compose.yml down
docker compose -f infrastructure/mysql-orders-compose.yml down -v
docker compose -f infrastructure/mssql-inventory-compose.yml down -v
docker compose -f infrastructure/mariadb-billing-compose.yml down -v
```

Notes:
- `-v` removes volumes and **deletes local database data**.
- Avoid `-v` unless you explicitly want a clean slate.

---

## Summary

Once these containers are running, the system infrastructure is ready and individual services can be started locally.
