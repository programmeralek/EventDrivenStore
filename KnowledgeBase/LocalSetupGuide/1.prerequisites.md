# Local Setup — Prerequisites

This document outlines the required tools and environment needed to run EventDrivenStore locally.

The goal is to ensure **environment parity** and avoid hidden dependencies.

---

## Required Software

You must have the following installed locally:

### Core Tooling
- Docker (latest stable)
- Docker Compose v2
- Git

### Language Runtimes
- Java 25 (for Orders Service)
- .NET 9 SDK (for Inventory Service)
- Node.js 20+ (for Billing Service)

### Optional (Recommended)
- IntelliJ IDEA or VS Code
- DataGrip / DBeaver / SSMS
- Kafka UI or CLI tools

---

## Required System Resources

Recommended minimum:
- 8 GB RAM
- 4 CPU cores
- ~10 GB free disk space

---

## Environment Variables

Each service uses a local `.env` file or `application.yml` for configuration.

**No secrets are required** for local development.

---

## What You Do NOT Need

You do NOT need:
- Cloud accounts
- Managed Kafka
- External databases
- CI/CD pipelines

Everything runs locally via containers.

---

## Summary

Once these prerequisites are met, the system can be bootstrapped deterministically using Docker.
